
Introduction
1.	Factory pattern is one of the most used design pattern in Java. This type of design pattern comes under creational
	design pattern as this pattern provides one of the best ways to create an object.

2.	In Factory pattern, we create objects without exposing creational logic to the client and refer to newly created 
	object using a common interface.



Implementation
1.	We are going to create an IShape interface and concrete classes implementing the IShape interface. A Factory class 
	ShapeFactory is created as a next step.

2.	Program.cs, our demo class, will use ShapeFactory to get an IShape object. It will pass information (CIRCLE/ RECTANGLE/ 
	SQUARE) to ShapeFactory to get type of object it needs.


Required Steps for Implementation
Step 1: Create an interface: IShape.cs
Step 2: Create concrete classes implementing the same interface: Rectangle.cs, Square.cs, Circle.cs
Step 3: Create a Factory to generate object of concrete class on given information: ShapeFactory.cs
Step 4: Use factory to get object of concrete class by passing an information such as Type: Program.cs
Step 5: Verify the output.
