Introduction
1.	Flyweight pattern is primarily used to reduce the number of objects created and to decrease
	memory footprint and increase performance. This type of design pattern comes under structural
	design pattern as this pattern provides ways to decrease object count thus improving the 
	object structure of application.

2.	Flyweight pattern tries to reuse already existing similar kind objects by storing them and
	creates new object when no matching object is found. We will demonstrate this pattern by
	drawing 20 circles of different locations but we will create only 5 objects. Only 5	colors
	are available so color property is used to check already existing Circle objects.



Implementation
1.	We are going to create an IShape interface and concrete class Circle implementing the IShape
	interface. A factory class ShapeFactory is defined as a next step.

2.	ShapeFactory has a HashMap of Circle having key as color of the Circle object. Whenever a 
	request comes to create a circle of particular color to ShapeFactory, it checks the circle
	object in  its HasMap. If object of Circle is found, that object is returned otherwise a
	new object is created, stored in hashmap for future use, and returned to client.

3.	Program, our demo class, will use ShapeFactory to get an IShape object. It will pass information 
	(red/ green/ blue/ black/ white) to ShapeFactory to get the circle of desired color it needs.



Required Steps for Implementation
Step 1: Create an interface: IShape.cs
Step 2: Create concrete classes implementing the same interface: Circle.cs
Step 3: Create a Factory to generate object of concrete class based on given information: ShapeFactory.cs
Step 4: Use the Factory to get object of concrete class by passing an information such as color: Program.cs
Step 5: Verify the output.
