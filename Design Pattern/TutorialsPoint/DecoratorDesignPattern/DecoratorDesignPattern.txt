Introduction
1.	Decorator pattern allows a user to add new functionality to an existing object
	without altering its structure. This type of design pattern comes under structural
	pattern as this pattern acts as a wrapper to existing class.

2.	This pattern creates a decorator class which wraps original class and provides 
	additional functionality keeping class methods signature intact.

3.	We are demonstrating the use of decorator pattern via following example in which
	we will decorate a shape with some color without alter Shape class.



Implementation
1.	We are going to create an IShape interface and concrete classes implementing the 
	IShape interface. We will then create an abstract decorator class ShapeDecorator 
	implementing the IShape interface and having IShape object as its instance variable.

2.	RedShapeDecorator is concrete class implementing ShapeDecorator.

3.	Program, our demo class, will use RedShapeDecorator to decorate IShape objects.



Required Steps for Implementation
Step 1: Create an interface: IShape.cs
Step 2: Create concrete classes implementing the same interface: Rectangle.cs, Circle.cs
Step 3: Create abstract decorator class implementing the IShape interface: ShapeDecorator.cs
Step 4: Create concrete decorator class extending the ShapeDecorator class: RedShapeDecorator.cs
Step 5: Use the RedShapeDecorator to decorate IShape objects: Program.cs
Step 6: Verify the output.
