Introduction
1.	In Strategy pattern, a class behavior or its algorithm can be changed at run time. This 
	type of design pattern comes under behavior pattern.

2.	In Strategy pattern, we create objects which represent various strategies and a context
	object whose behavior varies as per its strategy object. The strategy object changes the 
	executing algorithm of the context object.



Implementation
1.	We are going to create an IStrategy interface defining an action and concrete strategy 
	classes implementing the IStrategy interface. Context is a class which uses a IStrategy.



Required Steps for Implementation
Step 1: Create an interface: IStrategy.cs
Step 2: Create concrete classes implementing the same interface: OperationAdd.cs, 
		OperationSubtract.cs, OperationMultiply.cs
Step 3: Create Context class: Context.cs
Step 4: Use the Context to see change in behavior when it changes its strategy: Program.cs
Step 5: Verify the output.
