Introduction
1.	Abstract Factory pattern work around a super-factory which creates other factories. This factory
	is also called as factory of factories. This type of design pattern comes under creational design
	pattern as this pattern provides one of the best ways to create an object.

2.	In Abstract Factory pattern, an interface is responsible for creating a factory of related objects
	without explicitly specifying their classes. Each generated factory can give the objects as per the
	Factory pattern.



Implementation
1.	We are going to create a IShape and IColor interfaces and concrete classes implementing these interfaces.
	We create an abstract factory class AbstractFactory as next step. Factory classes ShapeFactory and ColorFactory
	are defined where each factory extends AbstractFactory. A factory creator/generator class FactoryProducer is created.

2.	Program.cs, our demo class, uses FactoryProducer to get an AbstractFactory object. It will pass information 
	(CIRCLE/ RECTANGLE/ SQUARE for IShape) to AbstractFactory to get the type of object it needs. It also passes 
	information (RED/ GREEN/ BLUE for Color) to AbstractFactory to get the type of object it needs.


Required steps for Implementation
Step 1: Create an interface: IShape.cs
Step 2: Create concrete classes implementing the same interface: Rectangle.cs, Square.cs, Circle.cs
Step 3: Create an interface for Colors: IColor.cs
Step 4: Create concrete classes implementing the same interface: Red.cs, Gren.cs, Blue.cs
Step 5: Create an Abstract class to get factories for IColor and IShape objects: AbstractFactory.cs
Step 6: Create Factory classes extending AbstractFactory to generate object of concrete class based on given 
		information: ShapeFactory.cs, ColorFactory.cs
Step 7: Create a Factory generator/producer class to get factories by passing an information such as IShape 
		or IColor: FactoryProducer.cs
Step 8: Use the FactoryProducer to get AbstractFactory in order to get factories of concrete classes by passing
		an information such as type: Program.cs
Step 9: Verify the output.
